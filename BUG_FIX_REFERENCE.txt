🐛 NON-VEGETARIAN SELECTION BUG - FIXED
═══════════════════════════════════════════════════════════════════════════════

❌ PROBLEM
───────────────────────────────────────────────────────────────────────────────
When users said "non-vegetarian", system incorrectly selected "vegetarian"

User input:    "I would like to go with non-vegetarian"
System output: Selected "vegetarian" ❌
Result:        Showed vegetarian recipes instead of non-veg

Root Cause:    Substring matching without word boundaries
               "vegetarian" found inside "non-vegetarian"
               Matched before checking "non-vegetarian" option

✅ SOLUTION
───────────────────────────────────────────────────────────────────────────────
Rewrote nlp_engine.py keyword extraction with:

1. Word boundary checking
   • r'\bvegetarian\b' in 'non-vegetarian' → False ✓
   • r'\bvegetarian\b' in 'vegetarian' → True ✓

2. Sort options by length (longer first)
   • Process 'non-vegetarian' before 'vegetarian' ✓

3. Text normalization
   • Convert hyphens to spaces for consistent matching ✓

4. Word order verification
   • Words must appear in sequence, not scattered ✓

5. Negation detection
   • If option starts with 'non', verify 'non' in text ✓
