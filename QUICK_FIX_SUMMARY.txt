When users selected "non-vegetarian", recipes weren't filtered correctly.

Root Cause:
  Data format:  "non vegetarian" (SPACE)
  Code format:  "non-vegetarian" (HYPHEN)
  → Filter couldn't match, returned 0 results

Solution Implemented:
  1. Normalized both ends to use "non vegetarian" (SPACE)
  2. Added format normalization in filter function
  3. Handles both formats for backward compatibility
